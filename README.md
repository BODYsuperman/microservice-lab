# microservice

Java microservices learning project based on Spring Boot, Spring Cloud and MyBatis-Plus.

## Tech Stack

- Java 17
- Spring Boot
- Spring Cloud
- Spring Cloud Alibaba
- MyBatis-Plus
- MySQL
- Maven

## Project Structure

```text
hm-microservice
├── user-service
├── order-service
├── gateway
├── common
└── docs
```

## Features

- User service
- Order service
- Gateway routing
- Service registration and discovery
- MyBatis-Plus CRUD
- Microservice communication

## Getting Started

### Clone project

```bash
git clone your-repo-url
```

### Start services

```bash
mvn spring-boot:run
```

## Learning Notes

This repository is used for learning:

- Spring Cloud microservices
- Distributed architecture
- Service governance
- API gateway
- Database access with MyBatis-Plus
